# 📚 نظام المكتبة الإلكترونية وقراءة الكتب - E-Library Management System

![MySQL](https://img.shields.io/badge/MySQL-4479A1?style=for-the-badge&logo=mysql&logoColor=white)
![Web](https://img.shields.io/badge/Web-Portal-orange?style=for-the-badge)

بوابة رقمية تفاعلية لإدارة وتصنيف وتصفح الكتب والمراجع الأكاديمية والجامعية وتوفير إمكانية القراءة والتحميل المباشر.

---

### ✨ المميزات الرئيسية (Key Features)
1. **فهرسة وتصنيف متعدد الأقسام:** تنظيم الكتب حسب الأقسام (ديني، أدبي، تاريخي، علمي، تقني، روايات).
2. **محرك بحث سريع:** البحث عن الكتب بالعنوان أو اسم المؤلف أو الموضوع.
3. **عارض الكتب والتحميل المباشر:** قراءة الكتب مباشرة داخل المتصفح أو تنزيلها للأجهزة الشخصية.
4. **لوحة تحكم المشرف (Admin Control Panel):** إضافة الكتب، تعديل البيانات، إدارة التصنيفات، ومتابعة إحصائيات التحميل.

---

### 🛠️ البنية التقنية (Tech Stack)
- **Backend:** PHP
- **Database:** MySQL Relational Database
- **UI:** Bootstrap & Modern CSS
